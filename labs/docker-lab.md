# Docker Lab

## Objective
Learn the basics of containerizing an application using Docker.

## Concepts
- Images
- Containers
- Dockerfile
- Docker Hub
- Container lifecycle

## Example Commands
```bash
docker --version
docker images
docker ps
docker run hello-world
```

## Practice Tasks
1. Install Docker and verify the version
2. Run a sample container
3. Build a simple Docker image
4. Inspect container logs
5. Stop and remove containers

## Notes
Focus on understanding the difference between images and containers.
