# Linux Fundamentals

## Overview
Linux is a core skill in DevOps because most servers, containers, and cloud workloads run on Linux-based environments.

## Key Concepts
- Filesystem hierarchy
- Users and permissions
- Processes and services
- Package management
- Networking and logs

## Common Commands
- `pwd` – print working directory
- `ls` – list directory contents
- `cd` – change directory
- `mkdir` – create directory
- `rm` – remove files or folders
- `cp` – copy files
- `mv` – move or rename files
- `cat` – view file contents
- `grep` – search text
- `chmod` – change file permissions

## Practice Ideas
- Explore the filesystem
- Create and manage users
- Check running processes with `ps`
- Use `top` and `htop`
- Inspect logs in `/var/log`
