# DevOps Learning Repository

This repository is a personal space for beginner-friendly DevOps learning notes, concepts, and hands-on practice.

## Purpose

This repo helps me:
- revise core DevOps fundamentals
- document learning notes in one place
- practice real-world tools and workflows
- track progress from basics to advanced topics

## Learning Roadmap

### 1. Fundamentals
- Linux basics
- Shell scripting
- Networking fundamentals
- OS concepts
- Git and GitHub

### 2. Cloud & Infrastructure
- AWS / Azure / GCP basics
- Virtual machines
- Containers
- Infrastructure as Code

### 3. CI/CD
- Jenkins
- GitHub Actions
- GitLab CI
- Build pipelines
- Deployment automation

### 4. Containers & Orchestration
- Docker
- Kubernetes
- Helm
- Pod architecture
- Scaling and troubleshooting

### 5. Monitoring & Logging
- Prometheus
- Grafana
- ELK / EFK
- Application metrics
- Alerts and dashboards

### 6. Security & Best Practices
- IAM and access control
- Secrets management
- Security scanning
- Least privilege
- Vulnerability management

## Repository Structure

- `topics/` – conceptual notes and topic summaries
- `notes/` – personal study notes and quick references
- `labs/` – hands-on exercises, commands, and mini-projects

## Suggested Learning Order

1. Learn Linux and shell commands
2. Understand Git workflows
3. Practice Docker and containers
4. Learn basic networking and cloud services
5. Explore CI/CD pipelines
6. Add Kubernetes and monitoring
7. Focus on automation and security
